# Ari v0.3.17

Ari 0.3.17 lets agents design full themes, adds SnapShots for dropping another app's window into a draft, makes the agent's browser a live page you can use, and fixes new sessions and turns that could get stuck.

## Agent-made themes

- Ask an agent for a theme (`/ari theme <brief>`). A theme can now carry its own CSS, images, fonts and a wallpaper, not just colours and borders.
- The agent previews the theme for 30 seconds. Keep it from the bar at the top, or it reverts on its own. Ctrl/⌘+Alt+Shift+T always resets to a built-in theme.
- Previewing a theme and taking a screenshot of the window ask for your approval. Adding a theme to your library doesn't, because it changes nothing on screen.
- Theme CSS can't restyle the preview bar or the approve/deny buttons on approval cards, and can't load anything from the internet.
- Theme screenshots are written only to Ari's own temp folder.
- A theme that can't be read is dropped from the library instead of breaking your settings.
- Settings export and import carry a theme's files.

## SnapShots

- New and off by default (Settings → SnapShots, Windows only for now). Press the shortcut (Ctrl+Alt+P by default) in any app to capture its window and attach it to your current draft. Ari stays in the background and doesn't take focus.
- A short animation shows the capture landing in the composer. The animation and its sound can each be turned off, and Reduce motion is respected.
- If the draft is full, captures wait until an image slot opens. If the draft they were meant for is sent or closed first, they go to your current draft instead.
- The shortcut can't be set to one Ari or dictation already uses. If another app already holds it, Ari says so, and your other settings still save.

## The agent's browser

- The Browser panel shows the agent's page live, and you can click, type and scroll in it. Before, it showed a periodically refreshed picture that stretched with the panel.
- The agent's clicks and typing no longer pull your keyboard away from the chat box, and a page the agent is driving in the background keeps its focus between steps, so held keys and drags work.
- Navigating no longer waits an extra second when the page is docked.

## New sessions

- Text you type on the new-session screen is kept when you leave it. Opening a new session for the same project brings it back.
- Sending from the new-session screen no longer gets stuck on "Local creation is still unconfirmed", and one failed start no longer blocks every new session until Ari restarts.
- The new-session screen names its project in the titlebar, as sessions do, instead of over the wallpaper.

## Sessions and turns

- A session could get stuck with "a turn is already active" after its reply finished, until Ari was restarted. This happened when the git snapshot Ari takes before each turn never returned, for example in a repository using Git LFS. Each snapshot step now gives up after 60 seconds, and the turn runs without that checkpoint.
- Several sessions can work in the same project folder at once. A prompt is no longer refused because another session is running there. New sessions still prefer their own worktree when the folder is busy.

## Upgrade notes

Install over 0.3.16. Nothing needs migrating.

If you use a custom theme and later go back to 0.3.16 or older, switch to a built-in theme first. Older versions can't read the custom theme setting.

## Known gaps

- Installers are unsigned.
- SnapShots works on Windows only.
- The agent's browser was checked with Chromium's own input events and automated tests, not with a physical mouse and keyboard on every platform.
