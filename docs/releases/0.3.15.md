# Ari v0.3.15

Ari 0.3.15 tidies the titlebar, shows what agents do in the browser, and makes links and queued messages work the way you'd expect.

## A cleaner titlebar

- One panel button replaces the separate Changes, Files, Terminal and Browser icons. It opens the right sidebar on the tab you last used; the sidebar's own tabs switch between the tools.
- The project and session name no longer repeat in the titlebar. The sidebar already marks the open session. A session on another machine still shows that machine's name.
- Nothing slides under the minimize, maximize and close buttons any more.
- In a narrow window the bar drops words in order (provider name, branch, Git action label) and keeps the icons, instead of squeezing everything to a letter.

## Browser

- The Browser tab now shows the page of the session you have open, which is the page that session's agent drives. You can watch what the agent loads and type an address into the same page.
- When an agent navigates in the session you're looking at, the Browser tab opens. Agents in other sessions don't pull it open.

## Conversation

- HTML files an agent names are clickable: a link to one, or a path in backticks such as `dist/index.html`. They open in your default browser. A missing file says so.
- Queued messages with images can be steered into the running turn, images included.
- The column of prompt markers beside long conversations is gone. The scrollbar and Jump to latest remain.

## Upgrade notes

Install over 0.3.14. The page you browse by hand is now kept per session; before, one page followed you across every session.

Only `.html` and `.htm` files open from a click in the chat. Web links open in your system browser as before.

## Known gaps

- Installers are unsigned.
- Steering with images and agent browsing were checked by automated tests, not against every provider by hand. Codex, ACP agents and Ari Core receive steered images as file paths in the text; Claude receives the images themselves.
