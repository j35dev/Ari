# Ari v0.3.16

Ari 0.3.16 rebuilds the Changes panel, fixes new sessions that stayed on the start screen, says at once when OpenCode runs out of usage, and makes the composer show the right model, reasoning level and queue.

## A cleaner Changes panel

- One header row replaces the sub-tabs, the branch row and the file-count row. A menu on the left chooses what you're looking at: working tree, staged, branch, this session, a single turn, a recent commit, or pull requests. Icons on the right switch split view, line wrap, the file tree and refresh.
- Changed files sit in one scrolling stack. Each file's header stays at the top while you read its diff, and files load as you open them.
- Hover a file to stage or discard it. Discard still asks first.
- When a turn is selected, a button in the header reverts to before that turn. It replaces the Turn checkpoints footer.
- Branch switching and stashes moved into the titlebar Git menu, next to commit and push.
- A clean working tree is one quiet line, with a shortcut to this session's changes.
- Code colours in diffs are readable on light themes.

## New sessions

- Sending the first prompt from the new-session screen now opens the session. Before, the agent could start while the screen stayed on a blank new-session draft.
- The model and reasoning level you pick are remembered for the next new session. Switching to another model of the same agent keeps the level when that model offers it.
- The new-session screen shows the model's name and your level from the start, instead of a raw model ID or "Choose".

## Composer and sessions

- Opening a session shows that session's own model at once, not another agent's for the first second.
- A message that was already sent no longer lingers in the queue, and the queue no longer shows one you can't remove.
- The send and stop button can no longer show a blurred mix of both icons.
- Delegated agents show their agent's logo (Claude, Codex, and so on) instead of a letter from their title.

## Agent errors

- When an OpenCode model runs out of usage, the turn now ends within seconds with OpenCode's own message (for example "Free usage limit reached …"). Before, Ari waited 20 minutes and then said only that the agent stopped responding.
- The same goes for other account problems OpenCode reports, such as an exhausted quota, missing credits or a rejected API key. Temporary rate limits are still left to OpenCode to retry.
- When any ACP agent goes silent, the error now includes the last error it printed, if it printed one.

## Sidebar and titlebar

- The titlebar names the open session's project again. The session's own name stays in the sidebar.
- In the Sessions view, drag a card onto another to rearrange them. New sessions appear at the top, and cards you've placed stay where you put them. Dropping a card on a pane still opens it there.
- Archiving the session you're on no longer pops the Archived list open.

## Upgrade notes

Install over 0.3.15. Nothing needs migrating. Your arrangement of Sessions cards is saved on this computer only.

The Changes panel's "Viewed" checkbox and its file navigator with search and history are gone. The file tree, with its filter, is one click away in the header, and recent commits are in the header menu.

## Known gaps

- Installers are unsigned.
- The Changes panel has no find-in-diff bar yet.
- The usage pill can't show OpenCode's remaining free usage, because OpenCode has no way to read it. Running out shows in the chat instead.
- Card rearranging and the Changes panel were checked by automated tests and in the development build, not on every platform by hand.
