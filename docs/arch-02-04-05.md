# arch-02/04/05 — Shell, providers, transcript status

## App shell (M2)

- Frameless window per platform: Windows `titleBarOverlay` (native snap/max/min),
  macOS `hiddenInset`, Linux custom controls rendered by `shell/Titlebar.tsx`.
  Window bounds persist via the settings store (`window` section), saved on
  resize/move/maximize.
- Navigation is state-based (`railView`) rather than URL-routed for v1; the view
  registry lives in `App.tsx`. TanStack Router is provisioned for when deep
  links arrive.
- Tray with Show/Quit; single-instance lock focuses the existing window.

## Providers (M4)

- One adapter interface (`@ari/providers/driver`); seven drivers registered at
  boot in `apps/desktop/src/main/rpc.ts › buildRegistry`: claude, codex,
  opencode, grok, pi, hermes (synthesized fixtures) and ari-core (built-in).
- Detection scans PATH plus well-known dirs per OS; auth status is read-only
  probing of each CLI's own credential files. Ari never performs OAuth.
- CLI transports use each tool's JSON mode; native lines map onto the normalized
  `AgentEvent` union through pure mappers tested against recorded fixtures
  (`__fixtures__/*.jsonl`). Flag drift fails soft into diagnostics text.
- The engine (`apps/desktop/src/main/engine.ts`) persists decider-approved
  events to journals, executes turns through adapters, coalesces text parts at
  ~120ms, guards every append behind an interruption flag (late adapter events
  can never overwrite a settled turn), and streams journal events to
  subscribers over one IPC channel with per-subscription ids.

## Transcript (M5)

- Block-granular virtualization: messages flatten to stable-keyed rows
  (`msgId#partIndex`); windowing via an in-tree hook mirroring the
  tanstack API subset needed (dynamic measurement, overscan, programmatic
  scroll).
- Markdown renders through unified → remark-parse → gfm → breaks →
  rehype-sanitize → stringify; raw HTML is dropped, href schemes restricted.
  Shiki highlights fenced blocks after mount with unknown-language fallback.
- Stick-to-bottom spring semantics: wheel-up beyond a 70px band unpins and
  shows a jump pill; new content re-engages only from the pill or manual
  scroll to bottom.
