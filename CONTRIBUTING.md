# Contributing to Ari

Thanks for helping build Ari — a local-first agent development environment.

## Before you start

1. Read [AGENTS.md](./AGENTS.md) — binding working protocol.
2. Skim [PLAN.md](./PLAN.md) and [PROGRESS.md](./PROGRESS.md).
3. For substantial work, open an issue first.

## Quick path

See README for install steps.

## Pull requests

Keep diffs small. Match style. One change per PR. Conventional commits. See AGENTS.md.

Do not force-push shared branches. Do not self-merge to main.

## Good first issues

Prefer docs, copy, small UI polish, tightly scoped bugs.

## Questions

Open a GitHub issue. AGENTS.md wins for protocol.
